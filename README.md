# Atlas OT Trip Net Pay Calculator (distribution)

This repo exists only to serve the GitHub Pages site below. It is auto-published
from a private source repo on every release and contains nothing but the
finished, already-vetted `index.html` file.

**Live app:** https://lolaunderway747.github.io/atlas-ot-calculator-pages/

- No build step, no dependencies, no network calls ever — verify with:
  `grep -c 'fetch(\|XMLHttpRequest\|http://\|https://' index.html`
- Ships with blank paycheck defaults. No personal payroll data of any kind.
- Works offline, including as an iPhone home-screen web app.
- This repo's own git history contains nothing but release snapshots — no
  development history, no drafts, no personal files.
